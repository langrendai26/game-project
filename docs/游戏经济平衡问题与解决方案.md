# 三界模拟器 · 游戏经济平衡问题与解决方案

## 一、问题描述

在将测试脚本的 Mock 数据替换为真实数据后，测试暴露出**初始经济不足以支撑炼丹系统**的核心问题。

### 1.1 具体数据

| 项目 | 数值 |
|------|------|
| 初始金币 | 1000（[Shop.gd:76](file:///d:/d--混沌修真诀-/scripts/Shop.gd#L76)） |
| 购买全部炼丹材料所需金币 | 2205 |
| 实际可购买花费 | 915 |
| 剩余金币 | 85 |
| **金币缺口** | **1205** |

### 1.2 无法购买的材料

| 材料 | 单价 | 需求数量 | 总价 | 跳过时余额 |
|------|------|---------|------|-----------|
| 慈悲幡 (compassion_banner) | 150 | 1 | 150 | 85 |
| 金莲花 (golden_flower) | 180 | 3 | 540 | 85 |
| 长生草 (longevity_herb) | 200 | 3 | 600 | 85 |

### 1.3 受影响的丹方

高价材料缺失直接导致以下丹方在游戏前期**无法炼制**：

| 丹方 | 等级 | 缺失材料 | 影响 |
|------|------|---------|------|
| 大悲丹 (compassion_pill) | 良品 | 慈悲幡×1 | 慈悲心增长路径中断 |
| 长寿丹 (longevity_pill) | 上品 | 长生草×2 + 金莲花×1 | 寿命延长途径断绝 |
| 解脱丹 (liberation_pill) | 极品 | 金莲花×1 | 解脱进度受阻 |
| 佛元丹 (buddha_pill) | 佛品 | 金莲花×3 | 终极丹药不可达 |

只有 **定心丹、般若丹、净化丹** 三个基础丹方能在前期正常炼制。

## 二、根因分析

### 2.1 金币获取渠道单一

当前金币来源仅有：

| 渠道 | 类型 | 金币范围 | 问题 |
|------|------|---------|------|
| 初始金币 | 一次性 | 1000 | 无法循环获取 |
| 任务奖励 | 一次性 | 50-5000 | 主线/支线完成后枯竭 |
| 出售物品 | 循环 | 物品原价×0.3 | 需有物品可卖 |

**缺失的关键循环**：地图探索作为核心玩法，目前**不产出金币**（[MapSystem.gd](file:///d:/d--混沌修真诀-/scripts/MapSystem.gd) 的 `karma_reward` 仅含 merit，无 gold 字段）。

### 2.2 地图掉落物品失效

地图探索的物品掉落使用了**无效的 item_id**（[MapSystem.gd:389-393](file:///d:/d--混沌修真诀-/scripts/MapSystem.gd#L389-L393)）：

```gdscript
"材料": [
    {"id": "herb", "name": "灵草"},      # item_database 中不存在
    {"id": "bamboo", "name": "竹材"},    # item_database 中不存在
    {"id": "stone", "name": "石料"}      # item_database 中不存在
]
```

这些 ID 在 [Inventory.gd](file:///d:/d--混沌修真诀-/scripts/Inventory.gd) 的 `item_database` 中均未定义，导致 `add_item()` 静默失败，玩家探索后**拿不到任何掉落物品**，也就无法通过出售换取金币。

### 2.3 高级材料无替代获取途径

慈悲幡、金莲花、长生草目前**只能在商店购买**，没有以下常见替代途径：
- 地图探索掉落
- 任务奖励
- 炼丹副产品
- 境界突破奖励

## 三、解决方案建议

### 方案 A：修复地图掉落 + 添加探索金币奖励（推荐）

**核心思路**：让地图探索成为金币和材料的循环来源，形成"探索→获得材料→出售换金币→购买所需材料→炼丹"的闭环。

**改动点**：

1. **修复 MapSystem.gd 掉落物品 ID**，替换为 item_database 中真实存在的材料：
```gdscript
"材料": [
    {"id": "sacred_ash", "name": "圣灰"},
    {"id": "lotus_petal", "name": "莲瓣"},
    {"id": "incense_powder", "name": "香粉"},
    {"id": "golden_flower", "name": "金莲花"},  # 高级地点才掉
    {"id": "longevity_herb", "name": "长生草"}  # 高级地点才掉
]
```

2. **在地点数据中添加 `gold_reward` 字段**，探索成功后给金币：
```gdscript
# 欲界村落
"village": {
    "gold_reward": {"min": 10, "max": 30},  # 随机金币
    ...
}
```

3. **按境界分配掉落池**：欲界掉基础材料，色界掉中级，无色界掉高级（金莲花、长生草）

**优点**：形成完整经济循环，玩家有持续动力探索
**工作量**：中等（改 MapSystem 掉落表 + 加金币奖励逻辑）

### 方案 B：降低高级材料价格 + 分级解锁

**核心思路**：让前期丹方用低价材料即可炼制，高价材料留给后期。

**改动点**：

1. **调整 Shop.gd 价格**：
   - 慈悲幡：150 → 80
   - 金莲花：180 → 100
   - 长生草：200 → 120

2. **调整 AlchemySystem.gd 配方**，降低高级丹方的高价材料数量：
   - 长寿丹：长生草 2→1，金莲花 1→1（总价 220→220，仍贵但可达）
   - 佛元丹：金莲花 3→1（留给后期境界）

**优点**：改动小，快速见效
**缺点**：治标不治本，仍缺循环经济；降低价格会削弱高级丹药的稀缺感

### 方案 C：添加每日任务金币奖励

**核心思路**：通过每日任务提供稳定的循环金币收入。

**改动点**：

1. **在 Quest.gd 的每日任务中增加 gold 奖励**：
```gdscript
"daily_morning_recitation": {
    "reward": {"exp": 30, "merit": 50, "gold": 20, "items": []},
    ...
}
```

2. **添加炼丹相关每日任务**：完成 3 次炼丹奖励 50 金币

**优点**：符合游戏惯例，玩家有每日目标
**缺点**：需要实现每日重置逻辑；金币产出较慢

### 方案 D：出售价格提升 + 出售渠道扩展

**核心思路**：提升出售回报率，让"卖东西"成为可行收入。

**改动点**：

1. **调整 Shop.gd 的 `get_item_sell_price`**：回收价从原价×0.3 提升到原价×0.5
2. **让炼丹产出的丹药可出售**，且高价丹药卖价更高
3. **初始 6 件物品中有可出售的冗余**（如多余的净水、莲花）

**优点**：不改产出端，只改回报端
**缺点**：0.3→0.5 仍不够买高价材料；需配合方案 A 才能形成闭环

## 四、推荐实施顺序

建议**组合实施**，按优先级排序：

| 优先级 | 方案 | 理由 |
|--------|------|------|
| P0 | 方案 A（修复掉落+金币） | 解决根因，形成经济循环 |
| P1 | 方案 C（每日任务金币） | 补充稳定收入来源 |
| P2 | 方案 B（调价） | 微调平衡，非必须 |

方案 A 中的"修复掉落物品 ID"是**必须修复的 Bug**（当前地图掉落完全失效），应优先处理。

## 五、验证标准

实施后应满足：
1. 初始金币 1000 可购买足够材料炼制至少 2 种基础丹方
2. 探索 5 次后累计获得金币 ≥ 100，材料 ≥ 3 件
3. 所有 7 种丹方在合理游戏进度内（约 30 分钟）均可炼制
4. 出售探索掉落的材料可获得有意义金币（≥ 单次探索金币奖励的 50%）
